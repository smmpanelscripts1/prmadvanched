# PRM Advanced

Blueprint extension for Pterodactyl / Blueprint.

From **Admin → Settings** you can set:

- Login / reset / 2FA logo
- User panel background
- Auth background (login, register, password reset, new password, 2FA)
- Captcha: hCaptcha, reCAPTCHA v2, or Cloudflare Turnstile on login / password reset / 2FA
- Active sessions on `/account` (list and revoke unknown devices)

## Version

`1.3.0`

## Install

Copy into Blueprint extensions and run `blueprint -install prmadvanched`.
